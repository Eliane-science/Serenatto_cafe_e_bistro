# Loja Online - Curso de Desenvolvimento

Este repositório acompanha o curso de desenvolvimento de uma loja online, utilizando HTML, CSS, Bootstrap 5 (nova versão) e JavaScript.
#
### Tecnologias Utilizadas:

- HTML5
- CSS
- Bootstrap 5 (última atualização)
- JavaScript
#

### Como Executar o Projeto

1. Clone este repositório na sua máquina:
git clone <URL do repositório>
2. Abra o arquivo index.html no seu navegador ou, se preferir, utilize um servidor local (como o Live Server no VS Code).
